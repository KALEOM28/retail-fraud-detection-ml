# Retail Fraud Detection using Machine Learning

## Overview

This project analyzes retail transaction data and detects fraudulent transactions using Machine Learning.

## Features

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Fraud Detection
* Random Forest Classifier
* Data Visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Project Workflow

1. Load Dataset
2. Data Exploration
3. Feature Engineering
4. Train-Test Split
5. Random Forest Training
6. Fraud Prediction
7. Performance Evaluation
8. Visualization
